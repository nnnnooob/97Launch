# Lite 主界面

## 窗口约束

- 固定 800 × 450 逻辑像素，横向 16:9；随 Windows DPI 缩放，禁止用户拉伸、最大化及全屏。
- 沿用统一浅灰底色 #f7f8fa，文字 #303640，次要文字 #737d8a，卡片 #ffffff，细边线 #e2e5ea；字体 Microsoft YaHei UI。
- 顶栏高 56 px，底色 #edf0f4，左侧为 21 px 粗体 97Launch，不显示品牌图标；右侧是灰色最小化、红色关闭圆点，点击区域 32 px。
- Windows 保留 WS_CAPTION、WS_SYSMENU、WS_MINIMIZEBOX、WS_THICKFRAME，通过 WM_NCCALCSIZE 自绘全部客户区，最小化发送系统命令。命中返回 HTCLIENT，拦截缩放及最大化。
- 窗口居中，保留原生拖动、DWM 浅色边框、系统阴影及可用时的系统圆角，不改变系统动画设置。

## 顶部导航

- 导航与品牌、窗口按钮处于同一顶栏，水平居中，宽 416、高 40。
- 依次为启动、实例、下载、传输、设置，16 px 图标在 13 px 文字左侧；下载与传输之间留 16 px 间隔，中央画 1 × 20 px 竖线。
- 参考本地 PCL MyRadioButton.xaml 与 RefreshColor 的单按钮状态设计：每项独立绘制高 32、半径 16 的胶囊底，点击区域仍高 40；取消跨按钮滑块。选中状态优先于按下和悬停，固定灰色 #cbd1d8，选中不透明、未选中按下 0.8、悬停或键盘焦点 0.45、普通状态透明。切换用 120 ms、悬停进入 90 ms、退出 150 ms 的透明度动画，文字和图标同步过渡，不使用白色背景、持续动画、模糊或离屏纹理。
- 启动页保留现有布局，其他分页显示分类菜单与轻量内容预览。
- 导航选中状态只由 currentIndex 决定，按钮不自行勾选或取消。鼠标切换不绘制键盘焦点圈；Tab/Shift+Tab 按正常顺序移动，左右键在导航项间切换并移动焦点，Enter/Space 可以激活，重复点击当前项不会取消选中。窗口按钮不再形成独立的 Tab 循环。

## 启动页中间区域

- 中间区域 x=260、y=68，宽 284、高 370，顶部与服务器列表标题的文字顶部对齐，底部距窗口边缘 12 px。
- 实例状态 y=0 / 高 116，图标 40 px、气泡 20 px；启动实例与实例设置 y=126 / 高 44；三项统计 y=180 / 高 50；当前游戏 y=240 / 高 130。统计标题与数值上下紧凑排放，数字 18 px，时间 12 px。
- 启动实例按钮保留白色启动图标，实例设置按钮宽 88，两按钮间隔 10。
- 各区域使用灰白卡片、细边线和静态圆角，标签采用灰色气泡；实例图标保留文字占位。
- 当前游戏位于中间区域最下方，展示标题、数量和空闲状态；当前仍为视觉占位，未连接游戏进程。底部导航保持删除。

## 左侧账号区

- 左侧白色底板由 LitePageHost 常驻绘制，启动页宽 244，位于固定顶栏下方。右侧用 12 px 水平渐变形成浅阴影过渡，不使用模糊或离屏效果。账号内容与底板分离。
- 顶栏下方的区域中央使用 64 px 容器，脸部 48 px、帽子层 56 px，参考 PCL MySkin.xaml 的尺寸关系，下方是昵称与登录方式。头像复用本地 Steve 皮肤裁切；底下的 80 px 静态 SVG 使用边缘与角部渐变绘制轻浅阴影，不使用 3D 模型或实时模糊。

## 右侧服务器列表

- 位置 x=560、y=64，宽 224、高 374，底部同样留 12 px，与中间相隔 16 px。去掉外层分组框，标题、条目数和图标刷新按钮独立放在上方，不再引入 Controls Basic 模块。
- 下方使用可滚动的竖向卡片列表，卡片高 82、间距 8，名称区高 32、底色 #edf1f5；沿用白色圆角底、细边线和按钮反馈，不使用模糊阴影。
- 去掉服务器图片，保留名称、延迟、人数、版本、状态色点与进入箭头。
- 当前两个示例条目仅用于视觉审核，刷新及服务器操作尚未接入业务。

## 页面切换

- 固定顶栏不参与动画；内容容器从 y=56 开始，裁切到窗口主体范围。
- 各页侧栏目标宽度为启动 244、实例 244、下载 156、传输 0、设置 168。白色底板做 180 ms 线性宽度动画，渐变阴影跟随边缘，收起到零时淡去。
- 旧内容用 80 ms 退出；侧栏菜单向左 14 px 并淡出，头像与账号信息仅淡出。右侧内容向上 6 px 并淡出。
- 退出结束后切换实际页面，更新最新请求的目标宽度；新侧栏菜单从左侧 18 px 进入，头像与账号信息仅淡入。右侧内容从上方 8 px 进入。
- 新内容等待 60 ms 后开始进入：透明度 120 ms，位移 160 ms OutCubic，总体约 300 ms。目标内容按最终宽度布局，动画中仅平移，避免反复换行。
- 退出阶段保留最后一次请求；进入阶段再收到请求时停止旧动画，从当前宽度与透明度接续。禁止退场内容响应点击，顶部导航保持可用。
- 启动页轻量视图常驻隐藏以保留界面状态，其他页面共用占位容器；菜单选中项逐页记录。当前没有业务扫描、网络请求或重型页面缓存。
- 实例页侧栏使用文件夹图标、名称及说明；下载分类包括图标加 Minecraft；传输不显示侧栏；设置展示常规、游戏与 Java、下载、外观分类。

## 当前空白分页

实例、下载、传输和设置页面已按要求清空：删除标题、占位卡片、提示文字、文件夹及分类菜单。顶部入口、白色侧栏底板、各页宽度及 180 ms 线性过渡保留。LiteSidebarMenu 源文件作为历史设计保留，不参与当前构建；下文历史页面切换描述中的菜单内容和文字位移动画当前不启用。

## 账号接入

- 无账号：显示“新建并选择一个账号以启动游戏”和添加图标，不显示正版验证限制提示。已有账号：显示真实头像、昵称、登录类型；鼠标进入账号白色区域后，类型下方以 140 ms 淡入切换图标，悬停提示“切换账号”，键盘焦点也可显示该入口。
- 切换弹窗展示账号列表、当前标记、移除与在线账号刷新按钮，右上角添加图标可进入三种登录方式。移除需要弹窗内确认。
- 正版：微软消费者设备码流程，显示并复制登录代码、打开系统浏览器；轮询包含 pending、slow_down、过期与拒绝处理，随后执行 Xbox Live、XSTS、Minecraft Token、所有权及玩家档案流程。保留原版 Token 刷新和 Minecraft 登录重试。没有浏览器内嵌组件。
- 离线：用户名、实时头像与 UUID 预览；UUID 沿用 WinUI 的 UTF-16 稳定哈希和版本位规则，同名账号更新并选中。
- 第三方：认证服务器地址 / 统一通行证 ID、登录名、密码、记住密码、注册链接；先验证缓存令牌，再刷新，最后使用密码登录。需要选择角色时弹出角色列表，确认后刷新绑定；取消不保存该次登录。
- 原生 Qt Network 异步请求，登录取消使旧回调失效并终止未完成请求。凭据不暴露给 QML，错误文本过滤当前密码和令牌；日志只记录成功或失败事件，不输出响应正文。
- 账号文件 `%LOCALAPPDATA%/97LaunchQt/accounts.json`；仅在不存在时复制导入 WinUI 账号文件，原文件后续不修改。加密沿用当前 Windows 用户 DPAPI 的 enc: 格式，原子保存；加密或写入失败时不使用明文降级，损坏的既有文件不覆盖。
- 默认头像按 UUID 选择 Steve / Alex；在线账号优先已有头像缓存，异步解析皮肤纹理，缓存前限制响应大小与图片尺寸。皮肤下载失败不影响账号登录。
- 弹窗按需加载、关闭后释放，表单内容可滚动以适应固定 800 × 450 窗口；账号数量绑定真实数据，其余游戏与服务器内容尚未接入。
- 正版 Client ID 配置与原版一致，使用 PCL_MS_CLIENT_ID 覆盖默认值；Minecraft 服务端对应用 ID 的准入要求仍然适用。未代用户执行真实账号授权。

## 最新账号排版与弹性动画

- 只参考 PCL 的账号区域排版，保留本项目灰色配色、圆角与 LiteButton 外观，不复制蓝色主题或其他页面布局。
- 添加按钮打开正版 / 离线 / 第三方登录三选一弹窗，选择后仅切换左侧白色区域，不直接开始网络登录。
- 正版左侧页：人像图标、登录按钮、购买正版 / 官网链接、返回及状态信息；点击登录才开始设备码流程，设备码使用独立弹窗。
- 离线左侧页：玩家 ID 输入、沿用 WinUI 的 UUID 预览、返回 / 创建。第三方左侧页：地址、账号、密码、记住密码、注册链接、返回 / 登录。表单使用现有账号逻辑，不增加新的 UUID 标准选项。
- 切换账号同样在左侧区域内展示头像、昵称、类型的紧凑列表，下方提供添加图标与返回；保留刷新登录和移除入口，移除确认也在左侧区域内显示。
- 白色侧栏底板点击分页后立即做 180 ms OutCubic 宽度变化。旧页面 120 ms 内轻微放大、缩小并淡出；等底板停止后再等 20 ms，让新页面以 0.94 → 1.025 → 1 的缩放进入，最后回落。
- 页面和账号子页的放大段 110 ms、回落段 190 ms；弹窗使用相同入场节奏，导航选中 1 → 1.07 → 1，按钮悬停轻微放大、按下缩小。均为事件触发动画，无持续运动。
- 此节覆盖前面旧版线性宽度、位移动画和将所有账号表单放进弹窗的设计说明。

## PCL 侧栏曲线与图标按钮修订

- 参考本地 `PCL/PCL-main/Plain Craft Launcher 2/FormMain.xaml.vb` 的 `PanMainLeft_Resize`：白色底板宽度在 180 ms 内使用 OutQuint（目标大于零）或 OutCubic（收起）；删除人为增宽 6 px 的两段动画，同宽页面不再抖动。仍保留本项目底板先到位、新内容后进入的顺序。
- 参考 `Controls/MyPageLeft.vb` 与 `Modules/Base/ModAnimation.vb`：侧栏内容从 0.96 缩放到 1，用 400 ms 的弱回弹；退出用 110 ms InQuad 到 0.95。原公式 `1-(1-t)^2*cos(1.5*PI*t)` 转为八段三次贝塞尔近似，交给 Qt 原生动画执行，不使用逐帧 JavaScript。账号子页复用相同进入曲线。
- 无边框图标按钮固定点击区域，删除整体悬停缩放，仅图标在按下时收缩、释放后轻回弹。默认没有边框，悬停用淡灰底和深灰图标，移除操作用淡红反馈；键盘焦点单独显示，悬停提示统一由组件提供。固定正方形图像尺寸，添加、切换、移除 SVG 统一为 24 px 网格和 1.8 px 圆头线条。
- 正版登录页删除购买正版和前往官网入口，仅保留登录、状态及返回档案。
- 此节覆盖上一节的底板两段回弹以及较早的页面进入动画描述。

## 正版授权窗口

正版登录改为 WebView2 原生窗口中的微软官方授权码 + S256 PKCE 流程，删除设备码弹窗及复制代码步骤。窗口按需加载，标题显示当前网页域名，成功回调、取消、错误或超时后释放，主窗口关闭时也取消授权。账号侧栏的排版和灰色外观保留。回调 URI 通过 `PCL_MS_REDIRECT_URI` 与应用注册匹配；默认 Client ID 当前不接受常用桌面回调，需要应用所有者完成注册配置。此节覆盖前文设备码登录说明。
