# 应用弹窗

## 共用组件

| 组件 | 用途 | 动效 |
| --- | --- | --- |
| `LitePopup` | 居中的模态窗口 | 130 ms 淡入、235 ms 轻微放大落稳；130 ms 缩小淡出，遮罩同步变化 |
| `LiteConfirmDialog` | 确认、警告、继续或取消 | 复用 `LitePopup`，确认和取消只处理一次 |
| `LiteMenu` | 操作菜单 | 110 ms 展开淡入、80 ms 收起淡出 |
| `LiteFlyout` | 下拉选择列表 | 与菜单一致，保留控件旁的定位 |
| `LiteToolTip` | 悬停提示 | 使用短动效，保留各入口的提示延时 |
| `LiteToast` | 下载、拖入结果提示 | 140 ms 淡入、200 ms 位移落稳，130 ms 淡出；普通下载停留 2.6 秒，批量结果 4.5 秒，错误 8 秒；悬停暂停 |
| `LitePopupTransition` | 共用进退动画 | 主弹窗与轻量浮层两种幅度，不旋转窗口 |

配色、边框和按钮沿用应用现有灰白风格。原生文件选择器和微软登录浏览器仍由系统管理。

## 业务入口

| 页面 | 已接入的弹窗 |
| --- | --- |
| 账号 | 添加方式、第三方角色选择 |
| 服务器 | 操作菜单、关联实例安装 |
| 启动 | 不兼容确认、内存提醒、崩溃提示 |
| 实例列表 | 添加文件夹、重命名、移除、删除实例、整合包导入 |
| 实例修改 | 提交修改、恢复修改备份 |
| 实例导出 | 导出整合包确认 |
| 游戏资源 | 详情、截图预览、Mod 更新选择、补齐前置、回退、删除、导入替换、兼容性确认 |
| 资源下载 | 在线资源选择、安装确认、整合包缺失文件继续下载 |
| 设置 | 按键捕获、从实例读取、退出授权 |
| 配对 | 获取 Token 帮助 |
| 全局拖入 | 同名 Mod：替换、跳过、取消剩余导入，可应用到本批其他同名文件 |

文件夹操作、资源行操作、Java 运行环境右键操作使用 `LiteMenu`。所有 `LiteComboBox` 下拉层使用 `LiteFlyout`；图标按钮、实例、服务器、启动状态等悬停提示使用 `LiteToolTip`。

## 生命周期

- 继续使用 Qt Popup 的 `open()` / `close()`，退出动画结束后才发出 `closed`。
- 确认框通过 `confirmed` / `rejected` 立即提交当前答案；`closed` 只负责收尾。
- 启动与传输问题以问题 ID 对应答案，关闭动画期间的新问题等待上一弹窗退出，避免误取消下一题。
- 保留各窗口原有的 Esc、点击外部关闭规则、输入验证和业务提交逻辑。
- 原生目录、打开/保存文件选择器及微软登录窗口不套应用弹窗组件。
- Minecraft 安装、整合包导入、实例组件修改自动打开传输页；其他下载在原页面显示 Toast。实例组件修改成功后返回启动页，失败或取消时保留传输页。手动下载 Mod 只保存选中的文件，不自动安装前置或按兼容性拒绝下载。
