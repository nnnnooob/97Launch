# 全局文件拖入

逻辑对照原 WinUI3 `MainWindow.DropImport.cs`、`DroppedFileReader.cs`。后者直接复用，拖入识别和 Mod 复制由专用后台任务处理，不进入传输列表。

- 授权后全窗口接收本地文件 URL，只接受复制操作。同一时间处理一批，路径忽略大小写去重。
- 松手时固定启动页选中的实例、实例实际资源目录、当前游戏文件夹。后续切换页面或选中其他实例不改变本批目标。
- `.jar`、`.zip`、`.litemod` 和禁用后缀由 Mod 清单识别；Modrinth、CurseForge 清单以及 ZIP 内单个 `.mrpack` 作为整合包。文件夹、无有效清单和其他类型逐项报告失败。
- Mod 保留 WinUI3 的加载器、游戏版本检查。资源目录按版本隔离设置确定；同路径或同内容文件跳过。同名不同内容可替换、跳过或取消剩余导入，可将选择应用到本批后续同名冲突。替换通过既有导入服务先回收旧文件，再提交临时文件。
- 整合包名称清理非法字符、Windows 保留名称并限制长度；目录或活跃队列重名时递增 `(2)`。使用既有 `downloadLocalPack` 队列安装，随后打开传输页。
- 某个文件失败不终止其余文件；取消剩余导入保留已经完成的 Mod 和此前识别的整合包。关闭应用或授权退出会取消后台处理。
- 汇总成功、跳过及错误数量，最多显示三条错误，全部错误写入后台/Qt 日志。Mod 导入完成通知实例资源和下载页刷新安装状态。

提示层使用现有灰白风格：160 ms 淡入并上移落稳、120 ms 淡出；离开延迟 100 ms 防闪烁。识别完成即收起提示层，再显示冲突弹窗。关闭系统动画时即时切换，高对比度下关闭背景着色与跟随光晕。
