# 97Launch Qt

当前发布：**0.1.0-alpha.4 / 构建 4**。Qt Quick 界面配合 C++ 原生服务与自包含 .NET worker，已接入实例、资源、下载、传输、启动、Java 自动获取、服务器、配对授权和更新。

开发构建：`./build.ps1 -Run -QtSdk <Qt 6.6.3 MSVC x64 目录> -AuthorizationConfigPath <本机配置>`。

对外发布：`./publish-release.ps1 -BuildNumber 4 -Channel preview -QtSdk <SDK目录> -AuthorizationConfigPath <本机配置>`，生成 `artifacts/releases/0.1.0-alpha.4-build.4/97Launch.exe` 与签名清单。后续发布递增构建号。只需分发该 EXE；运行库首次展开后缓存复用，游戏目录位于 EXE 同级。详细机制见 [单 EXE 发布](docs/single-exe.md)。

以下保留开发过程记录；标注“本轮”的段落描述当时迁移范围，当前功能以本节和根目录更新记录为准。

## 首次准备与登录运行库

首次授权进入后，依次检查本地数据、扫描实例、检索 Java，并准备头像与微软登录环境；成功保存 schema 1 标记后下次跳过。缺少 WebView2 Runtime 时，从微软下载并验证安装程序签名后自动静默安装。安装失败可重试或稍后安装；后续微软登录也会检查并补装。详情见 [首次进入](docs/first-startup.md)。

本地单 EXE 开发包可使用 `./publish-release.ps1 -BuildNumber 4 -VersionSuffix alpha.4-local -SkipSigning`，不生成后台发布签名清单。

当前展示固定 800 × 450 逻辑像素（16:9）的 Lite 主界面。标题栏与内容统一浅灰底色，左上角使用纯文字品牌，右上角使用灰色最小化圆点和红色关闭圆点。边框、圆角和阴影由 Windows DWM 处理。支持系统拖动和原生最小化，禁止拉伸、最大化及全屏。

顶部导航为启动、实例、下载、传输、设置，下载与传输之间用竖线分隔，顶栏使用浅灰底。启动页分为三栏：左侧宽 244 的白色账号区，头像、昵称和登录方式居中，头像采用 PCL 的 48 px 脸部、56 px 帽子层比例，并有静态渐变阴影；中间宽 284，向上对齐服务器列表标题，依次展示实例状态、启动及实例设置、三项统计、当前游戏；右侧宽 224，展示紧凑的无图标服务器卡片。

页面切换时复用白色侧栏底板，宽度按启动 244、实例 264、下载 172、传输有任务时 224 / 无任务时 0、设置 168 做 180 ms 缓出变化。底板先到位，等待 20 ms 后页面以轻回弹进入。实例页展示文件夹侧栏和可搜索的分组列表，下载、传输和设置页面已接入对应业务与独立内容。无边框图标按钮只改变图标颜色。

账号功能已接入原生 C++ / Qt Network：无账号时显示添加入口；已有账号显示真实头像、昵称与登录类型，悬停白色区域可切换账号。添加方式由三选一弹窗选择；正版入口、离线及第三方表单、账号列表均在左侧白色区域内切换。只参考 PCL 的排版，保留现有灰色配色和控件外观。支持保存、切换、移除、刷新登录和多角色选择。实例、服务器及任务仍为视觉占位。

Qt 账号保存在 `%LOCALAPPDATA%/97LaunchQt/accounts.json`，首次运行兼容导入 WinUI 版 `%LOCALAPPDATA%/97Launch/accounts.json`，后续单独保存。密码、Access Token、Refresh Token 使用当前 Windows 用户 DPAPI 加密，原版账号文件保留。正版登录沿用 WinUI 的默认 Client ID 和 `PCL_MS_CLIENT_ID` 环境变量；能否完成 Minecraft 授权仍受该应用 ID 的服务端资格限制。

本轮修改前的源码、界面、构建文件及可执行文件备份在 `D:/97launch/backups/qt-before-pkce-20261025-035358`，不包含账户数据和凭据。

点击正版登录后按需创建 WebView2 官方授权网页。使用授权码、S256 PKCE 与随机 state；回调地址、state 和参数唯一性校验通过后兑换令牌，继续 Xbox Live → XSTS → Minecraft 登录。密码和验证码由微软网页处理，应用不读取网页输入，也不注入脚本。取消、失败或十分钟超时会释放窗口，成功回调也会释放窗口；浏览器缓存位于 `%LOCALAPPDATA%/97LaunchQt/webview2-login`，不启用浏览器密码保存。刷新令牌继续使用 DPAPI 加密。
