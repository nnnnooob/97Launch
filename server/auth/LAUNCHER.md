# WinUI 启动器接入 · 2026-10-23

## 已接入

- 欢迎页为原生 WinUI 控件：左侧单行输入一次性 Token，右侧 MC 山谷，固定曲线边界、鼠标视差与按钮指针柔光。标题统一为 Welcome，输入提示为“输入 Token”，移除群内申请说明和自动进入提示；申请方法保留在帮助弹窗。高对比度或较小可用区域简化为单栏，关闭系统动画时不播放位移动画。
- 欢迎窗口固定为 960 × 600 有效像素（按系统 DPI 换算；屏幕工作区不足时只在创建时适配一次），禁用拖拽缩放、最大化、标题栏双击放大与全屏模式；进入主界面后恢复原窗口尺寸及缩放/最大化能力。
- 登录窗口不写入主窗口尺寸记录，退出授权前保存主窗口布局；场景图片在自身面板内裁剪，避免视差和负边距造成曲线边缘漏图。
- `AuthorizationWindow` 独立承载欢迎/验证页，`MainWindow` 只承载主界面；设备授权通过后才创建主窗口、主视图模型、加载首页和预取游戏元数据。先激活主窗口再销毁验证窗口，不在同一 HWND 内缩放切换。
- 验证窗口不参与主窗口尺寸持久化。退出授权或授权失效时，主窗口保存布局、关闭弹层并隐藏，重新创建验证窗口；再次授权后恢复原主窗口并关闭验证窗口。主动关闭任一当前窗口会退出启动器，不结束 Minecraft 进程。
- Token 兑换、设备验证、心跳与退出均调用真实后端；不使用机器人或管理密钥，不内置临时配对 Token。
- `%LOCALAPPDATA%\97Launch\authorization.dat` 使用当前 Windows 用户 DPAPI 加密，并通过临时文件原子替换保存设备凭据、服务器地址、设备信息及最近验证时间。
- `installation-id.txt` 只保存随机 UUID，重启/退出后保留，不采集硬件指纹。
- 每次启动验证设备；已授权期间每 15 分钟验证并心跳。网络故障保留凭据，最近成功校验 72 小时内可使用本机缓存，超时需联网。明确失效/撤销立即回到配对页；正在运行的 Minecraft 进程不会被结束。
- 取消或退出会使当前请求世代失效，迟到的兑换/校验响应不能恢复已经取消的授权状态。
- 设置 → 管理 → 启动器授权：所属 QQ、来源群、设备名、配对/验证时间、重新验证和退出本机授权。Minecraft 账号仍在左上角单独管理。

## 服务地址配置

源码不包含实际部署地址。配置文件格式见仓库根目录 `authorization-server.example.json`。

- 开发/发布：在仓库根目录创建 Git 忽略的 `authorization-server.json`，构建和发布会将其复制到程序目录。
- 本机覆盖：`%LOCALAPPDATA%\97Launch\authorization-server.json` 优先于程序目录配置。
- 未提供配置时，欢迎页提示授权服务配置无效，不会连接占位地址。

```json
{"base_url":"https://auth.example.com:18443/","private_ca":false}
```

使用系统信任证书时保留 `private_ca: false`。仅在使用配套专用 CA 时显式设为 `true`；此时公钥证书仅用于配置的服务主机和端口，继续检查证书链、主机名/IP、有效期和服务器用途。CA 公钥不是凭据，私钥仅保留在服务器。没有关闭 TLS 验证或修改系统信任。

客户端拒绝重定向、远程 HTTP、URL 用户信息、查询、片段和非根路径。更改服务地址会要求重新配对，避免向其他服务发送旧凭据。机器人密钥和管理密钥不能放入客户端配置。

发布包需包含实际服务配置，客户端使用时必然能看到所连接的地址；源码脱敏不等于隐藏运行时连接地址。
